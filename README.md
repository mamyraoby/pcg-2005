# PCG 2005

This repository contains a structured data of the PCG 2005 of Madagascar.

The site is installable as a Progressive Web App and caches the page and
`data/pcg_2005.json` for offline use. Open it once while online to download the
data and service worker, then use your browser's install option to add it to
your phone. Service workers require HTTPS (or `localhost` during development).
